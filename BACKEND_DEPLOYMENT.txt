🐛 TROUBLESHOOTING CORS ERRORS:
-------------------------------

Error: "Access-Control-Allow-Origin" header missing
Solution:
  ✅ Set CORS_ORIGIN=https://meet.xluma.in in Render
  ✅ Restart backend service
  ✅ Check backend logs show correct origins

Error: Origin not allowed by CORS
Solution:
  ✅ Check CORS_ORIGIN matches frontend URL exactly
  ✅ Remove any trailing slashes
  ✅ Check for typos in domain name
  ✅ Verify backend restarted after env var change

Error: Preflight request failed
Solution:
  ✅ Backend must respond to OPTIONS requests
  ✅ Check backend is running and accessible
  ✅ Verify no firewall blocking requests

Error: CORS works locally but not in production
Solution:
  ✅ Local uses http://localhost:3000 (allowed)
  ✅ Production must use https://meet.xluma.in (check CORS_ORIGIN)
  ✅ Verify env vars are set in Render, not just locally

📝 BACKEND CORS CONFIGURATION:
------------------------------

The backend now uses a whitelist approach:
- Checks incoming request origin
- Allows if origin is in allowedOrigins array
- Blocks and logs if origin not allowed
- Allows requests with no origin (mobile apps, curl)

Allowed origins are:
1. http://localhost:3000 (hardcoded for dev)
2. https://meet.xluma.in (hardcoded for prod)
3. https://meet-x-luma.onrender.com (hardcoded for backend)
4. process.env.CORS_ORIGIN (configurable via env var)

This ensures security while allowing legitimate requests!
