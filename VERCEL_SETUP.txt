🚀 VERCEL ENVIRONMENT VARIABLES SETUP
======================================

Go to: https://vercel.com/your-project/settings/environment-variables

📋 SET THESE EXACT VALUES:
--------------------------

1. NEXT_PUBLIC_API_URL (REQUIRED - Backend API URL)
   Name: NEXT_PUBLIC_API_URL
   Value: https://meet-x-luma.onrender.com
   Environment: ✅ Production ✅ Preview ✅ Development
   
2. NEXT_PUBLIC_SOCKET_URL (REQUIRED - Socket.IO URL)
   Name: NEXT_PUBLIC_SOCKET_URL
   Value: https://meet-x-luma.onrender.com
   Environment: ✅ Production ✅ Preview ✅ Development

3. NEXT_PUBLIC_APP_URL (Optional - Frontend URL)
   Name: NEXT_PUBLIC_APP_URL
   Value: https://meet.xluma.in
   Environment: ✅ Production ✅ Preview ✅ Development

⚠️ IMPORTANT NOTES:
-------------------
- All variables are prefixed with NEXT_PUBLIC_ (works in both server and client)
- You MUST check all three environments (Production, Preview, Development)
- After saving, you MUST redeploy (not just rebuild)

🔄 AFTER SETTING VARIABLES:
---------------------------
1. Click "Save" on each variable
2. Go to "Deployments" tab
3. Find your latest deployment
4. Click "..." menu → "Redeploy"
5. Wait for deployment to complete

🧪 VERIFY IT'S WORKING:
-----------------------
Method 1: Test Backend Connection
- Visit: https://meet.xluma.in/api/test-backend
- Should show all tests passing with backend URL

Method 2: Check Health Endpoint
- Visit: https://meet.xluma.in/api/health
- Should show backend status and URL

Method 3: Create Event
- Go to: https://meet.xluma.in/create
- Create a test event
- Should redirect to event page successfully

🐛 TROUBLESHOOTING:
-------------------
Problem: Still using fallback URL
Solution: 
  - Make sure variable name is exactly: NEXT_PUBLIC_API_URL
  - Check "Production" environment is selected
  - Redeploy (not just rebuild)
  - Clear browser cache

Problem: CORS errors
Solution:
  - Backend must have: CORS_ORIGIN=https://meet.xluma.in
  - No trailing slash in CORS_ORIGIN
  - Restart backend after changing CORS

Problem: Backend unreachable
Solution:
  - Verify backend is running: https://meet-x-luma.onrender.com/health
  - Check backend logs for errors
  - Ensure backend accepts requests from frontend domain
