🚀 VERCEL ENVIRONMENT VARIABLES SETUP
======================================

⚠️ CRITICAL: You MUST set these in Vercel Dashboard

Go to: https://vercel.com/your-project/settings/environment-variables

📋 SET THESE EXACT VALUES:
--------------------------

1. BACKEND_URL (Server-side - REQUIRED)
   Name: BACKEND_URL
   Value: https://meet-x-luma.onrender.com
   Environment: ✅ Production ✅ Preview ✅ Development
   
2. NEXT_PUBLIC_SOCKET_URL (Client-side - REQUIRED)
   Name: NEXT_PUBLIC_SOCKET_URL
   Value: https://meet-x-luma.onrender.com
   Environment: ✅ Production ✅ Preview ✅ Development

3. NEXT_PUBLIC_APP_URL (Optional)
   Name: NEXT_PUBLIC_APP_URL
   Value: https://meet.xluma.in
   Environment: ✅ Production ✅ Preview ✅ Development

⚠️ IMPORTANT NOTES:
-------------------
- BACKEND_URL is NOT prefixed with NEXT_PUBLIC_ (server-side only, more secure)
- You MUST check all three environments (Production, Preview, Development)
- After saving, you MUST redeploy (not just rebuild)

🔄 AFTER SETTING VARIABLES:
---------------------------
1. Click "Save" on each variable
2. Go to "Deployments" tab
3. Find your latest deployment
4. Click "..." menu → "Redeploy"
5. Wait for deployment to complete

🧪 VERIFY IT'S WORKING:
-----------------------
1. Go to: https://vercel.com/your-project/deployments
2. Click on your latest deployment
3. Click "Functions" tab
4. Click on any API route (e.g., /api/events)
5. Check logs - you should see:
   ✅ Events API Route - Backend URL: https://meet-x-luma.onrender.com

If you see:
   ❌ BACKEND_URL is not set! Requests will fail.
   
Then the environment variable is NOT set correctly.

🐛 TROUBLESHOOTING:
-------------------
Problem: Still seeing frontend URL in requests
Solution: 
  - Clear Vercel build cache
  - Make sure BACKEND_URL is set in "Production" environment
  - Redeploy (not just rebuild)
  - Check Vercel function logs for the ✅ message

Problem: CORS errors
Solution:
  - Backend must have: CORS_ORIGIN=https://meet.xluma.in
  - No trailing slash in CORS_ORIGIN
  - Restart backend after changing CORS

Problem: "BACKEND_URL not configured" error
Solution:
  - Variable name must be exactly: BACKEND_URL (case-sensitive)
  - Must be set in Production environment
  - Must redeploy after adding variable
